Remote Job Crawler

Remote Job Crawler searches currently-open remote jobs across public job boards and returns them in real time — title, company, location, salary band and category. No account, no API key, no stored database. Every search is a live request against the source feeds, so what you see was posted minutes ago, not months ago.

Use the widget above, or pick a curated search below. Applying always happens on the original board.

    How it works

    • You submit a keyword and a result count.
    • An edge Worker queries the Remotive and Arbeitnow public feeds in parallel.
    • Results are filtered by keyword, de-duplicated and normalised into one schema.
    • Listings render with a direct link to the original posting.

    Who it is for

    Developers, designers, DevOps and SRE engineers, data and ML people, technical writers and support staff looking for remote-only work — especially anyone tired of signing up to five job boards to see the same postings republished everywhere.

    Frequently asked questions

    Which job boards are crawled?

    Remotive and Arbeitnow. Both publish public remote-job feeds the Worker reads on every request.

    Is it free?

    Yes. No account, no key, no payment. Apply directly on the original board.

    Are the listings current?

    Yes — fetched at the moment you run a crawl, never cached in a database. Some roles disappear within hours because they were filled.

    Can I use the API directly?

    Yes: /api/crawl?q=your+keyword&limit=15 returns JSON. /api/health returns build and status.

    Why do some searches return nothing?

    Only currently-open roles are returned. A narrow keyword can legitimately have zero matches today — broaden the term instead of paging.
